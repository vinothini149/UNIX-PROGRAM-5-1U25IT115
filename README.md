# Linux Practical – Create a File Using echo Command

## Aim

To create a file and add content to it using the Linux `echo` command.

---

## Objective

Students should learn how to:

1. Use the `echo` command.
2. Display text on the terminal.
3. Create a file with specific content.
4. Append text to an existing file using `>>`.
5. Verify file contents.
6. Submit the practical through GitHub.
7. Understand automated testing using GitHub Actions.

---

# Algorithm

### Step 1

Open the Terminal on your Linux machine.

### Step 2

Understand the primary purpose of the `echo` command.

The `echo` command is used to display text or strings on the terminal.

Example:
